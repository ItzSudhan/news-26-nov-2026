The world's news of Thursday 26 November 2026 on one 1024×1024 front page. It carries 43 stories across 10 regions and 20 fields, and each one was first reported that day. Every story has a source tag (confirmed, official, reported or claim), and a date-check strip names the big stories left out because they were first reported earlier. The page is hand-written HTML/CSS/SVG (`layout/page.html`), rendered to `entry.png` with headless Chrome (`render.sh`). `main.ts` checks the image against the contest limits and copies it to the output folder. Sources for every story are in `stories.md`.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
